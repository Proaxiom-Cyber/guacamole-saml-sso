# Limit the first version to Guacamole on the installation host

The first version manages this Guacamole use case and runs on the machine that will
host the deployment. It serves IT administrators familiar with DNS, Cloudflare, and
Entra ID who want a fast provisioning process. A reusable provisioning framework and
remote deployment management remain possible later iterations; neither belongs in
the first version. The tool must support both temporary customer project access and
durable deployments through a command-line interface.
